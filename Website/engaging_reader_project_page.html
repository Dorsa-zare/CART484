Inclusive & Accessible Design Studio

Engaging Reader Help Page

This project focused on designing a help page for Engaging Reader, a platform that supports clearer and more accessible document reading. Through user testing, interface comparison, and iteration, we developed a help experience that uses focused task sections, simple written instructions, and short demonstration videos. Our final design responds directly to feedback about clarity, clutter, and usability by making key features easier to find, understand, and use.

Final Design Outcome

Final HTML help page with feature-based navigation, instructional videos, and simplified written guidance.

Project Focus

The goal was to explain major features in a way that was accessible, clear, and easy to navigate for users with a wide range of needs.

  • User testing and comparison of two design directions
  • Iteration based on feedback about clutter and readability
  • HTML prototype supported by instructional videos

Design Process

1
Prototype A/B

We created and compared two layout directions to test structure, hierarchy, and visibility.

2
User Feedback

Users liked visible information, but found some versions too small or cluttered.

3
Final Iteration

We refined the page into clearer feature sections with improved instructions and video guidance.
